# 內建動作資料庫

`data/exercise-catalog.json` 是自行整理的 21 個常見動作名稱、肌群分類與器材對應，沒有複製外部資料庫、圖片或教學文字，因此不引入外部資料集授權。這是初始清單，並非完整的動作或教學百科。

從「課表 → 瀏覽動作資料庫」進入，可搜尋中文、英文名稱與肌群，依動作模式或已清點的廠區器材篩選。資料隨 PWA 打包，離線可查詢，不需登入服務或 D1。

## 資料規則

- `id` 穩定且唯一，未來課表與訓練紀錄以它引用動作。
- `equipment` 外層任一組成立即可；每組內所有器材都必須有數量大於零的清點紀錄。`[[]]` 表示徒手即可。
- 槓鈴負重動作明列槓片，需要架或椅的動作也列出，不以單一槓鈴視為器材齊全。
- 器材類型模型未記錄握把配置、可承重或特定動作所需數量，因此篩選僅代表器材類型可用，不保證實際負重與場地適合。
- `alternatives` 是相同動作模式且主要肌群有交集的候選，再依選定廠區器材篩選；不代表重量、難度與訓練效果完全等價。
- 此階段只有查詢，尚未實作訓練中的占用狀態、疲勞評估或整堂課重排。

新增動作時同時補齊中英文名稱、動作模式、主要與次要肌群、器材組合及替代動作 id。`src/utils/exercises.test.ts` 檢查引用有效性與器材組合規則。
