# 完整備份與還原

右上「本機使用狀態 → 備份與還原」，可下載全部本機資料的 JSON。檔案包含尚未刪除的廠區、課表、已完成紀錄，以及已儲存的進行中訓練，不含登入狀態、cookie 或雲端憑證。

## 使用方式

1. 先儲存編輯中的課表或訓練。備份只讀取已寫入的本機資料。
2. 點「下載完整備份」，選擇系統提供的保存位置。iPhone／iPad 可透過系統檔案操作保存到 iCloud Drive；此處未取得 iCloud API 權限，也未提供背景同步。
3. 還原時選檔，先查看備份時間及廠區、課表、訓練數量，再確認新增副本。
4. 匯入後原有資料保留；廠區與課表名稱加上「匯入」。重複匯入會產生更多副本，不合併、不覆蓋。

## 格式與資料保護

- 固定 `format: reproute-backup`、`version: 1`，最大 10 MB。未知版本、損壞內容或非法資料整份拒絕。
- 單一廠區匯出的 JSON 使用原廠區清單匯入，不與完整備份混用。
- 所有新副本重新產生 id，並重新連結副本間的廠區、課表與訓練日；歷史快照的名稱與各組表現保留。
- 原來源已刪除的歷史也可還原，不會誤連結本機同 id 的其他課表。
- 三張資料表在同一 IndexedDB 交易還原；中途失敗整份回滾，不留下部分副本。
- 完整備份可以含一堂進行中訓練；若本機也有進行中訓練，匯入整份拒絕，先結束或放棄本機訓練後再重試。匯入成功可在今日訓練接續。
- 已刪除的資料不進入備份。本功能不是清空後還原，也沒有自動同步或加密服務。

Google Drive 尚待正式網址與 Web OAuth Client ID 設定。可共用 auth-service 的 Web Client，但需保留原回呼並加入 RepRoute 的已授權 JavaScript 來源；為獨立移除與維護，建議建立 RepRoute 專用 Client。前端只使用公開 Client ID，不使用 Client Secret 或服務帳戶金鑰；登入授權不等於 Drive 檔案授權。
