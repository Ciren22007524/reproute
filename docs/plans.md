# 手動課表

在「課表 → 新增課表」選擇模式：

| 模式     | 用途                                                     |
| -------- | -------------------------------------------------------- |
| 單堂課表 | 每份是一堂獨立訓練，當天自行選擇。固定一個訓練單元。     |
| 多日課表 | 一份包含多個命名訓練日，例如推／拉／腿，不自動綁定星期。 |

兩種模式共用動作與目標編輯器。模式在建立時選擇，本次不提供既有課表模式轉換。

## 編輯與儲存

- 填寫課表名稱；多日模式還可新增、命名、移動及刪除訓練日，至少保留一天。
- 從內建動作選擇動作，支援中英文搜尋。同一動作可重複加入，每列有獨立 id。
- 每列設定組數及每組目標，單位可選次或秒。初始 3 組 10 次只是可修改的輸入起點。
- 手機可用上移／下移調整動作順序；桌面可拖曳把手。訓練日也可用上下移排序。
- 名稱不可空白，每個訓練日至少一個動作；組數與每組目標必須是大於零的整數。
- 按「儲存課表」才寫入本機。儲存成功前保留草稿，失敗時可重試；離開未儲存的編輯頁會提醒。
- 同一課表在其他分頁修改或刪除時，舊分頁不可覆蓋新版；草稿保留，重新載入前會再次確認捨棄。

## 資料與範圍

IndexedDB 新增 version 2 的 `plans` 資料表，保留 version 1 的 `gyms` 與原廠區資料。課表及訓練日、動作列均以穩定 id 識別，順序以陣列保存；刪除課表採 `deletedAt` 軟刪除，預留同步標記。

目前課表只存在這台裝置，尚未有課表 JSON 備份或 D1 雲端同步。廠區的 JSON 備份不含課表。課表是可編輯的訓練模板，不是已完成的訓練紀錄；依既有需求，開始累積正式訓練紀錄前先完成登入與同步。

本次不改變登入，不開始訓練、不自動排星期、不依器材自動替換或重排；這些功能由後續訓練與推薦流程處理。
