# 本機訓練紀錄

本機功能不需登入；不會在 App 啟動時呼叫 `/api/me`。若正式網址仍有 Cloudflare Access 保護，那是部署端設定，需由使用者在後台另行調整；這次未取消任何既有遠端防護。

## 使用流程

1. 在課表頁建立並儲存單堂或多日課表。
2. 今日訓練選擇課表、訓練日與可選的廠區，再開始。
3. 每組可填實際重量（kg，可留白或零）、次數或秒數，以及可選的 RIR／RPE。
4. 「完成本組並儲存」會保存全部有效草稿；未完成組的修改可用「儲存進度」保存。重新整理後接續已儲存內容，離線也可寫入。
5. 至少完成一組後才能結束；若還有未完成組，確認後可結束部分完成的訓練。也可確認後放棄，不列入歷史。
6. 紀錄頁查看完成紀錄，或確認後刪除。歷史唯讀，不改寫已完成訓練。

## 資料完整性

- 課表、訓練日、動作與廠區名稱在開始時建立快照。改名、修改或刪除來源不影響既有訓練與歷史。
- 每台裝置同一資料庫同時只允許一堂進行中訓練；開始與版本檢查均在 IndexedDB 交易中進行。
- 其他分頁更新或結束後，舊分頁不可覆寫；未儲存草稿保留，重新載入前會提醒。
- 寫入失敗保留草稿，不部分更新。未儲存修改離開頁面或重整會提醒。
- 重量必須有限且不小於零；次數／秒數必須為正整數。RIR 為 0–10 整數；RPE 為 1–10，可使用半分。
- 每堂最多 500 組，避免異常課表耗盡瀏覽器資源。
- 重量總量只加總已完成的次數動作：重量乘實際次數；計時動作不混入公斤次數總量。
- IndexedDB version 3 新增 workouts，保留既有廠區與課表。放棄或刪除保留軟刪除標記。

目前不會自動替換器材、推薦重量或同步雲端。本機資料在清除瀏覽器資料時會遺失，可透過完整 JSON 備份保存與還原，見 `docs/backup.md`；原有單一廠區 JSON 不包含課表與訓練。
